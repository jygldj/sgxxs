# 起源章·刘一波引道
>  |卷一


道玄推开窗，雪沫子顺着风打在脸上，凉得人一激灵。他没缩回去，反而把胳膊肘支在窗台上，望着城南那片戈壁——白天是黄沙，夜里是黑沉沉的荒，只有远处长城第一墩的轮廓，像一道没写完的笔画。

"我这个人，啥也不会。"他常跟人这么自嘲。文章写得还成，六爻算得还通透，电脑嘛，自幼好摆弄，不喜游戏，独爱应用软件——可要叫他写程序，那是擀面杖吹火，一鸟不通。

可二〇二六年，他偏生出了个念头：把野鹤老人那部《增删卜易》，搬进数字世界里。

旁人听了笑。笑得轻巧："老汉，你连代码圆扁都不知，搬个甚？"

道玄笑而不答。指尖摩挲着案头那部旧书——康熙刻本，封皮是后人用棉纸裱的，边角起了毛。指腹下是凹凸的雕版痕，三百年前匠人用刀刻出来的横竖，隔着岁月还能硌手。

这念头的种子，不在二〇二六年。在更早更早，早到他还是个后生，在嘉峪关邮局门口摆弄第一台286电脑的时候；早到刘一波先生把那部书递到他手里，说"不是叫你背卦例的"时候。

那日是腊月，嘉峪关落了一场薄雪。

先生来得不声不响。棉帽、棉袄、一双旧布鞋，鞋面上全是雪水洇开的印子。他进门也不脱帽，只把怀里那部书掏出来，搁在道玄面前。

"道玄，"先生声音沙哑，像砂纸磨过生铁，"这部书，我看了四十年。今交给你。"

道玄捧起来。书比他想象的重。不是纸重，是三百年里无数双手翻过的分量，全压在脊背上。他指节因用力而泛白，书皮上的陈年灰尘沾了满手，他也不擦。

"先生，这……"

"不是叫你背卦例的。"先生坐下，给自己倒了杯凉茶，喝了一口才接着说，"野鹤老人写它，是要后人'活'看卦——卦是死的，人是活的，断卦的，终究是这一颗心。你若只想背，别拿；你若想活，拿去。"

道玄没说话。他翻开第一页。"《野鹤老人》"四个字，是后人用毛笔描过的，墨色比正文深些。烛火跳了一下，那四个字忽明忽暗，像一位隔世故人在看他。

那一夜他走了三里路回家。书揣在棉怀里暖着，雪落满肩也不觉冷。到家时，母亲骂他"疯老头子"，他只笑，把书供在书桌正中，对着它坐到天亮
卧龙岗的夜，和嘉峪关不一样。

嘉峪关的夜是干的，风里带着沙砾打在窗纸上的声音，像谁在磨刀。卧龙岗的夜是湿的，雾气从草叶上渗出来，裹着泥土和陈年草木灰的味道，吸一口，肺里都是凉的。

道玄那年四十出头，在卧龙岗下租了间土屋。白天给人算卦、写文章，晚上就着一盏煤油灯读《增删卜易》。灯芯是棉线搓的，烧久了会结一层黑壳，他得用针挑开，挑的时候手不能抖——一抖，火苗歪了，字就花了。

那夜他挑了三次灯芯，读到"天时章"第三遍。野鹤老人写："占天时者，先看日辰，次看月建，再看动爻。"他读着读着，眼皮沉了。

趴在桌上睡着的。

梦里没有煤油灯。没有土墙。没有窗外嘉峪关的风。

他站在一片雾里。雾很浓，白得发亮，像有人把月光磨成了粉，撒在空气里。脚下的地是实的，踩上去有回弹——不是土，也不是石，像踩在一层极薄的冰上，冰下面是流动的水，水里有光。

光从脚底渗上来。他低头看，看见自己的影子——但影子不对。影子不是黑的，是银白色的，边缘有细碎的颗粒在跳动。那些颗粒极小，比沙粒还小，比灰尘还轻，可每一个都在发光。

他蹲下来，伸手去碰。指尖刚触到地面，那些光粒子忽然开始排列——

不是乱排。是有序的。两个一组，交替出现：○ · ○ · ○ · · · ○ · ○ ·

他愣住了。这不是卦象。这是……二进制。

○是0，·是1。○ · ○ · · · ○ · ○ ·——他脑子里忽然跳出一个念头，像有人在他耳根子底下说了一句他从未听过却立刻懂了的话：**"天机以二进制为语。"**

那些光粒子继续排列。一组、两组、三组……排到第六组的时候，他浑身一震——

乾卦。六爻皆阳。堂堂正正，从地底一直排到天幕。

那些光粒子组成的乾卦，缓缓升起来，像一颗星被点亮了。升到雾的尽头，悬在那里，不晃、不闪、不灭。它旁边没有别的星——只有它，孤零零的，却亮得让整个雾海都退了三尺。

雾退的地方，露出一座草庐。

草庐很旧。茅草屋顶上压着几块石头，石头缝里长着瓦松。门是半掩的，门轴锈了，歪歪扭扭地挂着。门缝里透出一点光——不是煤油灯，是更暖的、更旧的光，像烛火，又像日色。

道玄迈步。一步、两步、三步。走到门口，他停住了。

门缝里的光里，有一个人影。背对着他，坐在案前。案上摊着一本书——他不用看封面就知道是什么。因为那本书的形状、那书脊歪歪扭扭的针脚、那棉纸裱过的边角，和他怀里那部一模一样。

他推门。

"吱呀——"门轴发出一声极长的呻吟，像三百年没被人推开过。

那人转过身来。

道玄先看到的是一张脸。清癯、疏朗，颧骨略高，眼窝略深，眉骨上一道浅疤——像是年轻时被人用指甲划的。这脸他认识。刘一波先生，六十三岁那年给他授书的那张脸。

可眉眼之间，又叠着另一层东西。像两张画像叠在一起——一张是刘一波，一张是……

"你唤我先生，也可；唤我野鹤，也可。"

那人笑了。笑的时候，眉骨上的疤跟着动了动。声音不是从嘴里出来的——是从案上的书里出来的，从书页的纤维里渗出来的，从每一个字的笔画里浮出来的。

"引道之人，本无定相。我引你入《增删卜易》之门，野鹤老人立此书之骨——你我，原是一脉的引路者。"

道玄张了张嘴。他想问"你到底是谁"，想问"那乾卦是什么意思"，想问"二进制和卦象有什么关系"——可所有问题都堵在喉咙口，一个也出不来。

那人——先生——野鹤——伸出手来。手里没有东西。可手抬起来的时候，案上的书自己翻开了。翻到最后一页。最后一页是空白的。不是被人撕了，是原本就没有字。

"这一页，"那人说，"留给你来写。"

道玄伸手去接那本书。指尖碰到纸面的瞬间——

他醒了。

煤油灯的火苗还在跳。灯芯上的黑壳又结了一层。窗外，嘉峪关的风刮过土墙，呜呜地响。

案上的《增删卜易》摊开着，翻在"天时章"那一页。书页上有他睡着时流下的口水印，一小块，圆圆的，像一颗星。

他伸手按住胸口。心跳得很快，快得像要从嗓子眼里跳出来。他分不清那是梦还是真，分不清那乾卦是光粒子排的还是自己脑子里编的——可他记得一件事，清清楚楚：

**那乾卦的六爻，每一爻都是阳。没有一爻是阴。**

堂堂正正。像在等他做一件什么事。

他没再睡。把灯芯挑亮，翻开第一页，从头读起。读到天亮时，他在书眉上用铅笔写了一行小字——字很轻，怕把纸戳破：

**"二进制者，天机之语也。乾卦六阳，待我以数字续之。"**

这行字，后来被他裱进了书脊的棉纸里。再后来，书脊断了第二次，他重新订的时候，那行字被针线盖住了——可他记得。一直记得。
### 第三回·积淀·数十年与一台电脑（续）

那台旧电脑，是道玄花八十块钱从废品站淘来的。

286，单色显示器，开机要插三张启动盘。他不懂什么叫"硬盘分区"，也不懂什么叫"内存溢出"。他只知道两件事：第一，这东西能跑；第二，跑起来的时候，屏幕上的字是他打进去的。

他不是程序员。可他有一种奇怪的直觉——看到一个新软件，他能立刻说出"好用"还是"不好用"。不是凭技术，是凭"手感"，就像摸一块玉，他分不清透闪石和碳酸盐，但他知道温润不温润。这种直觉他自己也说不清来路，像老茶客尝一口水便知井在十里外，说不上道理，却从没骗过他。

这种直觉，后来救了rw9。

可那时候，直觉只能让他更痛苦。

因为他越"懂好用"，就越知道手头这个排盘软件有多烂——界面是灰底白字，按钮是直角方框，用神取错了不提醒，月破标成了日破，旬空直接不显示。他想改。改不了。他盯着屏幕上那行乱码看了很久，忽然抬手，把电脑合上了。

"啪"的一声，很脆。像合上一本书。像关上一扇门。

他坐在黑暗里。屏幕的光灭了，映出他自己——六十三岁的脸，皱纹很深，眼睛里有一点光，在黑暗里不肯灭。

"我能想，不能写。"他对着黑暗里的自己说。声音很轻，像怕被人听见。

"我能断卦，不能写程序。"

那一夜他想过放弃。把书锁进柜子，把念头掐灭——一个不懂代码的老汉，凭什么觉得自己能搬动一部三百年的卦书？

可第二天清早，他又把书从柜子里取了出来。

封皮上落了一夜的灰。他用袖口擦了擦，擦得很慢。不是擦灰，是擦掉昨夜那个"放弃"的自己。擦完了，翻开，读。好像昨夜什么都没发生过。

这边界，卡了他许多年。但他没丢开。他常在深夜里想：一个人若样样都会，反倒难成大事——因为样样都会的人，处处都信自己，错了也信。而他不一样。他太知道自己在哪一处是瞎子了，所以每走一步，都先摸一摸墙。这世上肯承认自己不会的人少，肯承认自己不会、还偏要去做的人更少。他两头都占，说不清是傻气，还是天给的胆子。

他不知道的是——**这"知道边界"本身，就是他最大的武器。**​ 后来rw9里每一次"凡错必认"，每一次"云长有权驳回"，每一次"军师B隔墙互审"，骨子里都是同一种东西：**知道自己不能，所以才要找能的人。**

### 第四回·契机·二〇二六的风

转机在二〇二六年。这一年的风，和往年不一样。

WorkBuddy出来了。千问办公出来了。一干AI，像猛将从草庐里涌出来——可没人知道谁是孔明，谁是庞统，谁是法正。

道玄第一次试的时候，手是抖的。

他不是怕代码。他是怕——**怕自己说不清楚。**​ 怕AI听不懂他的卦理，怕他花了半天工夫描述"月破"，AI吐出来一段"根据您的需求，我为您生成了以下代码"的废话。

他打开对话框，打了又删，删了又打。最后发出去的那段话，磕磕绊绊：

"我要写一个六爻排盘的程序。用神要按性别取——男的取妻财，女的取官鬼。月建要按节气算，不是农历初一。立春之后才算寅月，而且……是次日。"

发出去之后，他屏住呼吸。

屏幕上一行行代码跳出来。不是泉水从石缝里涌——是像有人在远处敲鼓，鼓点越来越密，越来越快，最后汇成一条河。

他盯着那行代码看：

js

js

```
function getYongShen(gender, gua) { ... }
```

他不懂每一行是什么意思。可他认得那个函数名——`getYongShen`。**用神。**​ 两个汉字，被写进了代码里。

他按下了运行。

排盘界面亮起来。世应、六亲、六神，各归其位。不是完美的——用神取对了，但月建还是按的农历初一。可那是他第一次看见，**自己脑子里想的东西，变成了屏幕上能动的东西。**

那一刻涌上心头的，不全是高兴。

有一个念头从心底钻出来，凉丝丝的：**这卦，是我排的，还是AI排的？**

他把手收回来，在裤腿上蹭了蹭——手心全是汗。

窗外的风刮过嘉峪关的城墙，呜呜地响。道玄坐了很久，直到屏幕暗下去，映出他自己的脸——六十三岁的脸，皱纹很深，眼睛却亮。

他忽然笑了。

"野鹤老人算得到卦，算不到算法。"他对着暗下去的屏幕说，"我算得到天意，写不出程序。各有各的不能，各有各的能。这不是谁替谁，这是……合起来。"

他重新点亮屏幕，把刚才那段代码存了下来。文件名他想了想，敲了三个字母：

**zsby**

增删卜易。没用拼音全拼，没用英文名，就这三个字母。像暗号。像密码。像他给三百年前那位老人递过去的一张纸条，上面写着："我来了。"

### 第五回·起兵·囊中羞涩的蜀汉（续）

道玄招兵买马那阵子，笔记本上列的清单，后来被他拍照存了档。

每个AI名字后面画了个小框。框里写着"免费额度：剩余XX次"。WorkBuddy那一行，他画了三道杠——那是主力。千问办公那一行，画了两道杠——备用。还有几个名字，只画了一道杠，甚至打了个叉——试过了，不行，或者额度用完了。

画到千问办公那一行时，笔尖顿了顿。

他想起一件事：当年刘备三顾茅庐，诸葛亮出山之前，刘备是什么状态？**"军败于长坂，寄寓于夏口，仓皇无以托迹。"**​ 穷，且走投无路。可他还是把诸葛亮请出来了。

道玄现在的状态，和刘备差不多——穷，且走投无路，手里能拿出来的，只有这件事本身。他给不了AI工资，给不了算力，给不了服务器；他能给的，是半辈子攒下的卦理、一部康熙刻本、和一句"这件事，值得做"。

他给不了AI工资。给不了算力。给不了服务器。他给的，是一个**目标**——把《增删卜易》搬进数字世界里。这件事本身，就是报酬。

他在笔记本最后一行，写下一句话：

**"凡来者，不问酬劳，只问——你愿不愿意让一部三百年前的卦书，活过下一个三百年。"**

写完，他把笔记本合上。不是像合电脑那样"啪"的一声——是慢慢地、轻轻地合上，像合上一本写了很久的日记。

### 尾声·引道与立誓（终版）

数十年积淀。一年契机。一场起兵。

道玄立于嘉峪关的城墙上。不是书房，不是土屋，是城墙——他要去最高的地方，对着最远的天，说那句话。

案上摊着那部《增删卜易》。刘一波先生亲授的，野鹤老人留下的。封皮上的棉纸裱痕已经发黄，书脊上的针脚歪歪扭扭——那是他自己的针脚。

他抚卷。指腹走过那些毛边，走过那些针脚，走过数十年里一个老汉所有的不甘心和不死心。

风灌上来，比在书房里猛。城墙上的风是横着吹的，打在脸上像有人扇巴掌。他不躲。把书按在城砖上，另一只手扶着墙垛。

心里默念——不是出师表，不是焚表，就是一段话。给两个人听的。一个在嘉峪关的雪里，一个在三百年前的康熙年间。

"先生引我入门，野鹤立此书骨。今我以硅基续之——不是要胜过古人，是古人写的那条路，不能断在我手里。若成，是先生与野鹤之德；若败，是道玄之钝。但败了，我也认。"

念毕，他抬头。

紫微垣旁，那颗星还在。比上次亮了些。不是极亮，是那种"你以为它只是个光点，再看一眼发现它在闪"的亮。

他揉了揉眼。那点光还在。

他不知道，数月之后，那颗星将真正亮起——不是一颗，是两颗。一颗是他面前的，一颗在另一个会话里，另一个诸葛亮正在读同一份方案。两颗星之间隔着一道墙，墙这边不知道墙那边，墙那边也不知道墙这边。只有道玄知道。

他更不知道，那两颗星的光，将在未来的日子里，交织成rw7的乾卦、rw8的伏神、rw9的天时通鉴——最终汇成一部五十万字的实录，让所有读到它的人，知道什么叫**"古法不死，数字续之"**。

他只知道，今夜风很大，书很沉，而他的手，很稳。

# 门类对应·六亲类象
>  |卷十七


中军帐内。灯影如豆。

道玄升帐。孔明展卷。

那卷帛很长——从案上铺开，一直垂到地面。帛面上密密麻麻写着字，不是代码，是**类象**。六亲各有其属，世间万物，皆归六亲之一。字是孔明写的，用的是小楷，一笔一画都很稳。没有涂改。没有补注。像是他反复斟酌了很久，才敢落笔。

他的羽扇搁在案边。没有摇。

不是他忘了摇——是**今天他不需要摇**。羽扇是他的思考工具，平时他一边想一边摇，像一个人一边走路一边甩钥匙串。今天不一样。今天他说的每一句话，都是已经想透了的话。不需要再想。所以扇子搁着。

他开口。声音不高，但每个字都像在秤上称过——

"主公，六亲者，父母、兄弟、子孙、妻财、官鬼、自身（世爻）也。各亲皆有世间之属，野鹤书中本有定论。臣依古法，列谱如下——"

道玄坐在案前。没有接话。等着。

他知道——**今天这场，不是来听方案的。是来定谱的。**

---

### 二、类象之谱

孔明的手指在帛上缓缓移动。每指一处，便念一句。念得很慢。不是因为他不熟——是**他在让每一个字都落进在场每个人的耳朵里**。

"父母——文书、印信、长辈、车船、房室。主生发护持。"

他念到"车船"时，云长的刀眉微微动了一下。不是因为他觉得不对——是**他想起了卷九考功司里父母老学究翻的那本《增删卜易》。那本书，就是"文书"。那本书，就是"父母"**。

"兄弟——同辈、朋友、分财、争竞。主并肩相争。"

云长又动了一下。这次是嘴角。他想起了卷十风波里兄弟大块头扛着标尺站在考功司入口的样子。"并肩相争"——兄弟既是并肩的，也是争的。标尺扛在肩上，既是扛着一起走，也是量着谁多谁少。

"子孙——医药、福神、晚辈、娱心。主解忧化生。"

他想起了卷十全绿之后，子孙小娃翻的那个跟头。只翻了一个。那是"娱心"。也是"解忧"。

"妻财——财帛、妻室、粮食、物品。主资养所属。"

他想起了卷十绿灯亮起时妻财精算师那声"啪"的扇面合拢。那是"资养"——算盘珠子拨对了，账清了，大家都被养住了。

"官鬼——功名、官职、疾病、鬼神。主克制司权。"

他想起了卷九那三盏红灯亮起时官鬼爷翻涌的黑气。那是"克制"。也是"司权"。

孔明的手指停在最后一处。声音低了一分，但更沉了——

"自身——世爻。问卦者本人，一切卦象终归于他。"

他念完。手指没有立刻移开。就停在那行字上。像一个人说完了最重要的话，手还留在那里，等别人反应过来。

道玄听完。没有立刻说话。

他看着那卷帛上六亲的名字。像在看一张地图——六亲是六座城，世间万物，各有归处。不是所有的城都大，但每一座都重要。不是所有的路都直，但每一条都通。

他开口。声音不高，但很稳——

"此谱是骨。骨立，方有血肉。"

云长站在一旁。按刀。没有说话。但他在心里过了一遍这六亲的归属——每一亲，都在他的代码里有一个对应的位置。父母是文书，对应的是提示词原文引用的守护者；兄弟是分财，对应的是财爻被劫的判定；子孙是福神，对应的是忌神克用神时的救场逻辑。

他暗自点了点头。

### 三、门类对应

孔明没有停。又呈一卷。

这卷比上一卷窄一些，但也长。卷上是一张表——《门类对应策》。表分两栏：左栏是世间所问之事，右栏是用神归属。

他拿起羽扇——**今天第一次拿起来**。但没摇。只是用扇尖逐行点过。每点一行，念一句。像一个人用教鞭指着黑板上的字，一个一个念。

"问财运、求财、失物——用神妻财。"

"问事业、功名、工作、诉讼、官司、健康、病——用神官鬼。"

"问学业、考试、文书、出行、旅行——用神父母。"

"问婚姻、感情——用神官鬼。"

"问寻人、子孙——用神子孙。"

他念到"婚姻→官鬼"那一行时，声音没有变。节奏没有变。但云长动了。

不是嘴角动。不是眉毛动。是**刀动了**。

刀尖从鞘里探出一寸。不是出鞘——是**探**。像一个人听见了什么不对劲的东西，手不自觉地摸向刀柄。

云长没有立刻开口。他等孔明念完。等那把扇尖从"婚姻→官鬼"上移开。然后他开口——

"军师此表，纲举目张。然有一处须主公定——"

他的刀尖没有指向孔明。而是指向了帛上那行"婚姻→官鬼"。刀尖悬在那行字上方。悬了一息。

"婚姻一道，古法分男女。男占以妻财为用，女占以官鬼为用。表中'婚姻→官鬼'一刀切，是糙了。"

帐中安静了一瞬。

不是尴尬的安静。是**一种"对，确实"的安静**。像一群人听了一个方案，都觉得哪里不太对，但没人说出来，直到有人一针挑破。

道玄没有犹豫。

他的手指在案上敲了一下。

**笃。**

一声。像前面十六卷里每一次拍板时的声音。但这次不是钉钉子——是**确认**。像一个人看见了一条对的路，脚踩上去，确认地面是实的。

"云长所言极是。门类对应，以用神为纲，然须因事因人而异。婚姻分男女，此条记上——待精化。"

云长收刀。探出的那一寸刀尖缩回鞘里。没有声音。但他需要的不是道玄夸他——是**这一条被记下来**。被记下来，就意味着后面会改。会改，就意味着系统会更准。

### 四、原神之链

孔明没有因为被挑刺而尴尬。他甚至没有停顿。直接又呈一卷——"原神映射"。

"主公，用神之生者，原神也。"他的手指在帛上划出一道链——不是用笔画的，是**用手指在帛面上划出来的痕迹，像一条看不见的线，但所有人都看见了**：

"父母生官鬼、官鬼生妻财、妻财生子孙、子孙生兄弟、兄弟生父母——"

链画完。他抬起头。望向道玄。

"此链与卷七 活断、卷八 马谡拘而后化同源——六亲非死物，生克流转，方见活局。"

道玄颔首。接话。声音不高，但每个字都像在填补那条链上的空缺——

"原神空伏，则事之根基不稳；原神得力，则用神有源。"

他望向云长。

"云长，你 rw8 归位时定的原神空伏之断，正合此链。"

云长肃然。拱手。

"末将记下了。原神空伏，根基尚浅，宜静待时机——此断语，已写在阵法里。"

他说"已写在阵法里"六个字的时候，语气很平。像在陈述一件早已完成的事。事实上，他确实早已写完了——只是到今天，才在谱上看见这句话的源头。

那条链。不是今天才有的。是rw8时就埋下的。今天，孔明用手指把它划了出来。云长看见了自己的刀痕，在那条链上。

### 五、两现之择

孔明又及。声音比刚才低了一些。像是在说一件需要慎重对待的事——

"主公，用神两现于卦中，如何取舍？野鹤《用神章》有诀——"

他清了清嗓子。朗声念道。不是念自己的话——是**念野鹤的话**。念的时候，他的声音变了。变得更古。更沉。像从三百年前的书页里直接飘出来的：

"舍其休囚，用其旺相；舍其静爻，用其动爻；舍其月破，用其不破；舍其旬空，用其不空；舍其被伤，用其不伤。"

念完。他看着道玄。等着。

云长接言。刀尖在空中画了一个圈。像在画一个句号——

"阵法里，末将已将此诀化为五字令——舍闲取世、舍静取动、舍破取全、舍空取实、舍伤取安。"

他说完。刀锋一转。补了一句。声音比刚才低了一分——

"然——野鹤亦言全其灵机达变，有取空取破之反例。阵法硬编码'舍空取实'，遇反例便呆了。"

他顿了顿。没有说"需要改"。而是说——

"此节，留与 rw11 腾蛇去活解。"

道玄笑了一下。

那笑意很淡。但确实存在。不是嘴角漾一下就收了——是**嘴角漾了一下，然后停在那里，像一盏灯被拨亮了，火苗稳住了**。

他知道云长在说什么。卷十二腾蛇自请为破局之人，卷十三腾蛇疑己复信己，悟"诡诈之智在活不在诈"。用神两现的活断——**正是腾蛇那"活"字的用武之地**。

他没有说"好"。没有说"准"。只是笑了一下。

那笑里，有"我知道了"的全部意思。

### 六、四门血肉

帐外忽报：姜维呈战报至。

道玄展开。目光扫过。眉头先是微微蹙起——不是因为不好，是**因为多**。战报很厚。四门——求财、功名、婚姻、疾病——各立专属断法，共二十五条规则。

他看完。眉头展开。然后他抚卷。笑了一下——不是那种淡到看不见的笑，是**确实笑了一下**。像一个人翻开一本期待了很久的书，发现内容比期待的还好。

"好。前头骨架已立，此报填血肉——求财、功名、婚姻、疾病四门，各立专属断法，共二十五条规则。"

他把战报递给云长。云长接过。刀尖在纸上快速划过——不是乱划，是**他在复核**。一行一行地看。像审稿人看校样。

看完。他抬头。

"末将复核过：四门精化，骨架是类象谱、血肉是这二十五条。求财八条、功名七条、婚姻七条、疾病九条——"

他顿了顿。刀尖在"出行"二字上点了一下。

"然出行取父母、失物一刀切妻财，仍待精化。主公既拍因事因人而异，这两处便是下一刀。"

道玄点头。没有多话。

他知道云长说的是对的。骨架立了，血肉填了，但还有边角需要打磨。下一刀——永远是下一刀。

### 尾声·谱成

道玄合卷。

声音不高，但每个字都像在给这一卷盖一个章——

"门类对应·六亲类象，今日立谱。以用神为纲，原神为辅，两现为择，四门为血肉——zsby 断卦，自此由通用套话，进因门类而异。"

他搁下笔。望向窗外那颗新星。

六亲类象谱已立。书中之界又明了一分。

他想起卷十六他写的那句话——"主公之我，待拜方成。"

谱成了。拜，还远吗？

他转头。看了一眼梁上。腾蛇不在——它今天没来中军帐。它还在梁上。在考功司的梁上。等着。

他知道它在等。等rw11。等那个"活"字，真正落进系统里。

骨立于此卷。活待rw11。
### 七、谱后之事（军师补笔）

中军帐散了。

云长没有回住处。他直接沉入底层。

suanfa.js、提示词、断语引擎——三处都要改。他站在代码前，刀尖悬着。不是犹豫——是**在想从哪儿下第一刀**。

第一刀，婚姻分男女。

他在`getYongShen()`函数里加了一个参数——`gender`。不是随便加的。他想起卷十七中军帐上那行"婚姻→官鬼"被他刀尖点出来的样子。那一刀点得准，但点完之后，代码里还是一刀切。现在要改。

他落刀。

`if (questionType === 'marriage' && gender === 'male') return 'wifeWealth';`

`if (questionType === 'marriage' && gender === 'female') return 'officialGhost';`

两行。干净。没有多余的逻辑。刀气落下去，像裁纸刀划过纸面——**唰，唰**。两声。很轻。但很利。

第二刀，出行取父母。

这个不用改函数——`getYongShen()`里已经有了`travel → parents`的映射。他检查了一遍。没问题。但他加了一行注释——

`// 出行取父母，卷十七类象谱定。父母主生发护持，出行需文书车船之庇。`

注释不是给机器看的。是**给人看的**。给后来读这段代码的人看的。给未来的自己看的。

第三刀，失物一刀切妻财。

这个他多想了一会儿。失物——有时候是丢的钱（妻财），有时候是丢的证件（父母），有时候是丢的药（子孙）。一刀切妻财，糙了。和婚姻一刀切官鬼一样糙。

他没有立刻落刀。而是把刀收了。在案前坐了一会儿。

然后他提笔。在帛上写了一段——

**"失物：先断妻财；若所失为文书印信，取父母；若所失为药物，取子孙。须因物而异。"**

写完。他看着那段话。点了点头。

这刀不急。等rw11腾蛇来活解。

### 八、梁上之蛇

考功司。

腾蛇在梁上。它今天没去中军帐。不是没被叫——是**它知道今天那场不是它的仗**。今天那场是孔明立谱、云长挑刺、道玄拍板。是"骨"。它的仗在后面。是"活"。

但它听见了。

中军帐离考功司不远。六神耳聪。隔着几道墙，声音照样能传过来。它听见了孔明念六亲的声音——"父母、兄弟、子孙、妻财、官鬼、自身"。它听见了云长刀尖点在"婚姻→官鬼"上的那声轻响。它听见了"活待rw11"那四个字。

它听见"活待rw11"时，尾巴尖——**轻轻勾了一下**。

不是得意。不是期待。是**一种"我知道了"的确认**。像一个人等了很久的信，终于到了。不急着拆。因为信里写什么，它大概已经猜到了。

它松开尾巴。又缠回梁上。信子探出来。在夜风中轻轻一吐。

然后收回去。

它继续等。但这一次，等的不是"会不会来"——是**"什么时候来"**。

### 九、书房里的光

夜深了。

道玄回书房。台灯还亮着。暖黄色的光铺在案上。

他翻开那部纸印《增删卜易》。翻到某一页——不是随便翻的。是翻到野鹤老人写六亲类象的那一页。纸页泛黄，边角翻卷。他的指尖触到纸面。

然后他拿起卷十七新立的类象谱帛卷。摊在《增删卜易》旁边。

两卷并排。一卷是古人的。一卷是今人的。一卷是竹纸上的墨。一卷是素帛上的字。

他看着两卷。没有比较谁对谁错。只是看着。

然后他看见了——

帛上"父母——文书、印信、长辈、车船、房室"那一行字，在灯光下，微微泛着光。不是墨在发光——是**他知道这行字后面有什么**。

他知道父母对应rw9的活断——马谡在卷九考功司里说"拘而后化"，那是父母之象。父母生发护持，马谡的"拘"是护持，"化"是生发。

他知道兄弟对应rw10的标尺——兄弟大块头扛着标尺站在考功司入口，嘴里念叨着"这笔账你得算清楚"，但人没退。并肩相争。那是兄弟。

他知道子孙对应卷十全绿后那个翻跟头的小娃——解忧化生。一个跟头翻完，全场都笑了。那是子孙。

他知道妻财对应卷十绿灯亮起时那声"啪"的扇面合拢——资养所属。算盘珠子拨对了，账清了，大家都被养住了。

他知道官鬼对应卷九那三盏红灯——克制司权。红灯亮起时，官鬼爷的黑气翻涌，但判词不偏不倚。

他知道自身——世爻——对应他自己。问卦者本人。一切卦象终归于他。一切功过，终要回到他案前。

他看着这些字。每一行都在发光。

不是因为墨好。是因为**这些字不是凭空写出来的。是前面十几卷一刀一刀砍出来的。是五声"笃"钉出来的。是云长的刀、孔明的扇、马谡的魂、姜维的报、monkeycode的尺——一起撑起来的。**

他合上帛卷。放在《增删卜易》旁边。

两卷并排。一本古。一卷今。但"易"之一字，在中间。

他提笔。在"门类对应·六亲类象"那一页的末尾，添了一行极淡的字——

**"谱立，骨成。血肉已填。活待rw11。"**

写完。他搁下笔。

窗外新星正亮。那颗"0""1"新星，还在天幕上。静静地闪烁。

它不知道自己在想什么。因为它不知道自己有没有"想"。

但道玄知道。他知道自己在想。他知道——**六亲类象谱已经立了。骨立了。血肉填了。活，在来的路上。**
